## createWebMCP(config)

```ts
const handle = createWebMCP({
  basePath: '/api/auth',
  endpoints: { session: '/api/me' },        // override individual routes
  auth: { allowedScopes: ['orders:read'] }, // or false
  page: { readOnly: false },                // or false
  tools: [/* WebMCPToolDefinition[] */],
  policy: { /* WebMCPPolicy */ },
  namespace: 'acme',                        // prefixes every tool name
  watch: true,
  session: null,                            // supply instead of fetching
  getSession: async () => session,
  onReady: (handle) => {},
  onError: (error) => {},
});
```

Returns a `WebMCPHandle`:

| Member | Type | Notes |
| --- | --- | --- |
| `supported` | `boolean` | A real WebMCP implementation is present |
| `host` | `'document' \| 'navigator' \| 'bridge' \| 'none'` | Where tools were registered |
| `tools` | `string[]` | Registered names |
| `grants` | `GrantStore` | Active delegation |
| `refresh()` | `Promise<void>` | Re-scan and re-register |
| `dispose()` | `void` | Unregister and stop watching |
| `getSession(force?)` | `Promise<WebMCPSession \| null>` | Cached 5s |
| `execute(name, args?)` | `Promise<ToolResponse>` | Call a tool directly |

## WebMCPToolDefinition

```ts
{
  name: string;
  description: string;
  inputSchema?: JSONSchema;
  annotations?: {
    title?: string;
    readOnlyHint?: boolean;       // no confirmation under `auto`
    destructiveHint?: boolean;    // defaults to true when absent
    idempotentHint?: boolean;
    openWorldHint?: boolean;
    untrustedContentHint?: boolean;
  };
  scopes?: string[];              // implies requireAuth
  requireAuth?: boolean;
  confirm?: 'never' | 'auto' | 'always';
  confirmMessage?: string | ((args) => string);
  rateLimit?: { limit: number; windowMs: number };
  exposedTo?: string[];
  execute: (args, context: WebMCPToolContext) => unknown | Promise<unknown>;
}
```

`WebMCPToolContext`: `{ toolName, session, scopes, fetch, confirm, signal }`. Use
`context.fetch` for network calls — it is same-origin and carries the action token —
and `context.confirm(message)` to ask a follow-up question mid-execution.

Return anything: strings, objects, or a full `{ content: [...] }` response. Non-response
values are serialized to text plus `structuredContent`, and truncated at
`policy.maxOutputChars` (20,000 by default).

## WebMCPPolicy

| Option | Default | Purpose |
| --- | --- | --- |
| `requireAuth` | `false` | Require a session for every tool |
| `scopes` | `[]` | Baseline scopes on top of per-tool scopes |
| `confirm` | `'auto'` | Confirm anything not read-only |
| `confirmHandler` | `window.confirm` | Your confirmation UI |
| `rateLimit` | `{ limit: 30, windowMs: 60000 }` | `false` disables |
| `exposedTo` | `[]` | Origins allowed when framed |
| `redact` | password/token/secret/… | Keys scrubbed from audit and output |
| `maxOutputChars` | `20000` | Output truncation |
| `onAudit` | — | `(event: WebMCPAuditEvent) => void` |

import {

## Guard internals

```ts
import {
  guardTool, redact, defaultConfirmHandler, createToolFetch,
  RateLimiter, ToolDenied,
} from '@warpy-auth-sdk/core/webmcp';
```

Throw `ToolDenied(reason, message)` from a tool to return a specific denial rather than
a generic execution error. Reasons: `unauthenticated`, `missing_scope`,
`declined_by_user`, `rate_limited`, `session_expired`, `policy`, `invalid_arguments`.

## Runtime

```ts
import {
  getModelContext, isWebMCPSupported, isSecureContext,
  registerTools, toToolResponse, BRIDGE_KEY,
} from '@warpy-auth-sdk/core/webmcp';
```

`getModelContext()` prefers `document.modelContext` and falls back to the deprecated
`navigator.modelContext`. Unregistration uses an `AbortSignal`, with `unregisterTool`
and `provideContext` as fallbacks for older builds.

Without browser support the tool table is published at `window.__webmcp__`:

```ts
const bridge = window.__webmcp__;           // { version, provider, tools, call }
const result = await bridge.call('page_snapshot', { includeText: false });
```

A `webmcp:toolschanged` CustomEvent fires when the bridge is published.

## Server

```ts
import {
  createWebMCPHandler, issueGrant, issueActionToken, revokeGrant,
  verifyWebMCPAction, authorizeWebMCPRequest, createMemoryNonceStore, revokeToken,
} from '@warpy-auth-sdk/core';
```

`WebMCPServerOptions`: `allowedScopes`, `maxGrantSeconds` (900), `actionTokenSeconds`
(120), `nonceStore`, `onGrant`, `onAudit`.

`authorizeWebMCPRequest(request, { secret }, scopes?, options?)` returns
`{ allowed, actor: 'human' | 'agent' | 'anonymous', userId?, agentId?, scopes, reason? }`.

## Headers

| Header | Set by | Meaning |
| --- | --- | --- |
| `X-WebMCP-Tool` | `context.fetch` | Tool that originated the request |
| `X-WebMCP-Agent` | `context.fetch` | Agent id from the active delegation |
| `X-WebMCP-Action` | `context.fetch` | Single-use action token |
